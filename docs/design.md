# Design

## UI direction

- Use the existing Uno Material theme resources.
- Keep spacing clean and intentional.
- Prefer simple, readable surfaces over decorative complexity.

## Practical rules

- Reuse existing assets in `Assets/`.
- Keep the splash, icon, and launcher resources consistent.
- Do not add new colors or visual tokens without a clear need.
- Preserve the current shell-first experience and avoid abrupt view changes.

## Desktop and Android

- Desktop should remain responsive and predictable.
- Android should keep the splash-to-shell transition smooth and fast.
- Emulator validation is required for Android UI changes.
